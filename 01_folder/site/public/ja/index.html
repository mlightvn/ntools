機能

ファイル操作のすべてを、もっと速く

1 / 2 / 3 ペイン、それぞれにタブ

フォルダーを並べてそのままコピー。Ctrl+1 / 2 / 3 で切り替え、分割線をドラッグ、レイアウト全体を Ctrl+S でプロファイルに保存。

入力と同時に検索

入力中から結果が次々に表示され、近いフォルダーから順に並びます。単語の順序は自由、アクセントも無視: duong で「Đường」、cafe で「Café」。インデックス不要で常に最新です。

待たされない削除

NTFS ドライブでは、Del で巨大なフォルダーもほぼ一瞬でごみ箱へ。Shift+Del は rmdir /s /q 並みに速く、ロック中のファイルは最後にまとめて報告します。

Excel や Word へはリンクとしてコピー

ファイルで Ctrl+C すると、エクスプローラーにはファイルとして、Excel・Word にはクリックできるリンク (名前 → パス) として、メモ帳にはフル パスとして貼り付けられます。

ZIP と 7-Zip に対応

追加ソフトなしで ZIP 圧縮 (日本語ファイル名、4 GB 超のファイルにも対応)。7-Zip があれば .7z、ファイル名も隠せる AES-256 パスワード、「ここに展開」も使えます。

使い方に合わせたサイドバー

自分でピン留めするクイック アクセス、ブラウザーのブックマークのようにグループ分けできるお気に入り、最近のフォルダー、フォルダー ツリー、空き容量。

バックグラウンドでコピー、進捗も明確

コピーや移動はバックグラウンドで実行し、項目数・MB・速度・キャンセルを表示。置き換え / スキップ / 両方残す を 1 件ごとにも一括でも選べます。

6 つのテーマ

Void、Flux、Mono、Nexus (4 色のネオンが選べる HUD 風)、Glass (壁紙の上のすりガラス)、Light。背景画像やウィンドウの透明度も設定できます。

ダウンロード

ダウンロードして、実行するだけ

  1. ダウンロード

    nexplorer.exe、1.0 MB。ファイル 1 つで、インストーラーはありません。

  2. 専用のフォルダーに置く

    例: D:\Tools\nExplorer や USB メモリ。設定は exe と同じ場所の nexplorer.ini に保存されるため、書き込みできるフォルダーを選んでください (Program Files は不可)。

  3. 実行

    ダブルクリックで起動。タスク バーにピン留めすれば、いつでもワンクリックで開けます。

「Windows によって PC が保護されました」と表示されたら

詳細情報 → 実行 をクリックします。nExplorer は新しく、まだコード署名されていないため、SmartScreen がまだ認識していません。

削除するには

nexplorer.exe と nexplorer.ini を削除するだけ。ほかには何もインストールされていません。

最初からやり直す

nexplorer.ini を削除すると、設定・お気に入り・プロファイルがすべて初期状態に戻ります。

よくある質問

よくある質問

nExplorer は無料ですか？

はい。ダウンロードして、何台の PC でも使えます。

Windows エクスプローラーを置き換えるのですか？

並べて使います。エクスプローラー、デスクトップ、タスク バーはそのままです。ファイル作業は nExplorer で、それ以外はエクスプローラーで。

なぜこんなに速いのですか？

フォルダーをバックグラウンド スレッドで読み込み、エクスプローラーを遅くする要素を省いているからです: シェル拡張、サムネイル、検索インデックスを使いません。

設定はどこに保存されますか？

exe と同じ場所の nexplorer.ini です (お気に入り、クイック アクセス、プロファイル、テーマ、ウィンドウ配置)。2 つのファイルをコピーすれば、別の PC にも同じ環境を持っていけます。

7-Zip は必要ですか？

不要です。ZIP は内蔵されており、7-Zip がなければ Windows 付属の tar.exe で展開します。7-Zip があれば .7z、パスワード、その他の形式も使えます。

インターネットに接続しますか？

しません。nExplorer には通信機能がなく、テレメトリ、更新確認、広告もありません。ネットワーク共有のフォルダーを開いたときだけ、Windows のファイル共有が使われます。

対応している Windows は？

Windows 10 (バージョン 1607 以降) と Windows 11 (64 ビット) です。管理者権限は不要です。

無料・ポータブル、数秒で使い始められます。
