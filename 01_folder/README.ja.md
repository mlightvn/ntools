# nExplorer

Windows エクスプローラーの代わりに使う、軽量な Windows 用ファイルマネージャーです。

- `nexplorer.exe`（約 800 KB）1 つだけで動作します。インストール不要で、Windows 以外の DLL には依存しません。
- シェル拡張を読み込まず、サムネイルも作りません。フォルダーの内容はバックグラウンドのスレッドで読むため、10 万ファイルのフォルダーも 1 秒以内に開きます。
- 設定は exe と同じ場所の `nexplorer.ini` に保存されます。削除すると初期状態に戻ります。

## ビルド

MSYS2 UCRT64 の g++（`C:\msys64\ucrt64\bin`）が必要です。次を実行します。

```
build.bat
```

## 画面構成

```
┌──────────────────────────────────────────────────────────────────────────────┐
│ [New folder] ✂ ⧉ 📋 ✎ 🗑  [Terminal]                 ▭ ▭▭ ▭▭▭  🎨  [Default ▾] │  toolbar
├ FAVOURITES ───┬ [tab] [tab] [+]       L / ACTIVE ┬ [tab] [+]                 R ┤
│ QUICK ACCESS  │ ← → ↑  This PC › D: › Media ›  ⟳ │ ...                         │
│ DRIVES        │ Media  12 items                ☆ │                             │
│               │ Name        Type    Date    Size │                             │
│               │ 3 items          1 folder · 2 files                           │
├───────────────┴──────────────────────────────────┴─────────────────────────────┤
│ Tab Switch pane  Ctrl C Copy  Ctrl X Cut ...                  ● Hidden files off │  status bar
└──────────────────────────────────────────────────────────────────────────────┘
```

- **ツールバー**（常に表示）：New folder、Cut、Copy、Paste、Rename、Delete（Shift+クリックで完全に削除）、Terminal（現在のフォルダーで Windows Terminal か cmd を開く）。ボタンはアクティブなペインに対して動作します。右側には 1 / 2 / 3 ペインの切り替え、テーマの選択、プロファイルのメニューがあります。
- **テーマ**：ツールバーのパレットボタンをクリックします。**Void**（濃紺、既定）、**Flux**（濃い紫、拡張子ラベル付きのカラータイルのアイコン）、**Mono**（黒地に緑、すべて等幅フォント）、**Light**（Windows のアイコン）。タイトルバー、メニュー、スクロールバーの色もテーマに合わせて変わります。選んだテーマは `nexplorer.ini`（`[Window] theme=`）に保存されます。
- **ステータスバー**（最下部）：ショートカットの一覧。**Hidden files on/off** をクリックすると隠しファイルの表示を切り替えます（Ctrl+H と同じ）。
- ペイン（pane）は 1・2・3 つから選べます。ツールバーのレイアウトボタンか Ctrl+1 / 2 / 3 で切り替えます。ペインの間の区切り線をドラッグすると幅を変えられます。ペインごとにタブを持ち、新しいタブは **This PC** で開きます。アクティブなペインには `ACTIVE` と表示され、現在のタブにアクセントカラーの線が付きます。
- **タブ**：タブの `×` で閉じます（Ctrl+W、中クリックでも可）。タブを右クリックすると Close tab、Close other tabs、Close tabs to the right、Duplicate tab、New tab を選べます。タブバーの空いている所をダブルクリックすると新しいタブを開きます。
- **アドレスバー**：
  - 区切りをクリックするとその場所へ移動します。`›` でサブフォルダーを選び、`▾` で履歴を開きます。
  - 空いている所をクリック（または Ctrl+L）するとパスを入力でき、入力中に候補が出ます。
  - `%USERPROFILE%`、`/`、`\\server\share`、相対パスが使えます。ファイルのパスを入力すると、そのフォルダーを開いてファイルを選択します。
- **サイドバー**：
  - Favourites（お気に入り）は自分でピン留めしたフォルダーです。☆、Ctrl+D、右クリックメニュー、または Favourites グループへのドラッグでピン留めします。
  - 項目にマウスを乗せると、並べ替え用の ▲ ▼ ボタンが出ます。右クリックで名前の変更、削除、Move up / Move down ができます。
  - Quick access には、システムフォルダー、**Recycle Bin（ごみ箱）**、最近よく使った 8 つのフォルダーが並びます。
- **ごみ箱**（サイドバー、またはアドレスバーに `Recycle Bin` と入力）：全ドライブの削除済み項目をまとめて表示します。列は 名前 / 元の場所 / 削除日時 / サイズ / 種類 です。
  - Del または Shift+Del：すぐに完全削除します（確認あり）。
  - 右クリック：Restore（元の場所に戻す。同じ名前があれば両方残す）、Delete permanently、Empty Recycle Bin。
  - ファイルをごみ箱（サイドバー / アドレスバー）にドロップすると、ごみ箱へ移動します。
- **プロファイル**（ツールバー右端のボタン、または Ctrl+P）：
  - プロファイルには、ペインの数、各ペインの幅、アクティブなペイン、各ペインのタブ（順番・パス・選択中のタブ）を保存します。
  - レイアウトは **Save（Ctrl+S）を押したときだけ保存されます**。起動時は最後に使ったプロファイルを保存済みのレイアウトで開きます。一度も保存していないプロファイルは、すべてのペインが This PC になります。
  - プロファイル名の横（とタイトルバー）の ● は、現在のレイアウトが保存済みのものと違うことを示します。未保存の変更があるままプロファイルを切り替えると、保存するかどうかを確認します。
  - メニュー：プロファイルを選んで切り替え、Save profile、Save as new profile、Rename、Delete、Reset layout to This PC（表示中のレイアウトだけを変え、保存済みのプロファイルは変えません）。
  - ウィンドウサイズ、列、Favourites、Quick access は共通の設定で、プロファイルには含まれません。
- **列**：列見出しを右クリックすると、Date created、Date accessed、Extension、Attributes を表示 / 非表示にできます。列見出しをクリックすると並べ替えます。

- **Shift + マウスホイール**でファイル一覧を横にスクロールします。チルトホイールやタッチパッドの横スワイプでも横スクロールできます。

## 検索

**Ctrl+F** か **Ctrl+K** を押すか、ツールバー中央の検索ボックスをクリックします。入力中（または Enter）にすぐ検索が始まり、見つかった順にアクティブなペインへ表示されます。近いフォルダーの結果ほど先に出ます。対象は現在のフォルダーとそのすべてのサブフォルダーで、This PC ではすべてのローカルドライブを検索します。

| 入力 | 見つかるもの |
|---|---|
| `tai lieu` | すべての語を含む名前（順不同）：`Tài liệu học tập.docx`、`lieu-tai.txt` |
| `"bao cao"` | そのフレーズをそのまま含む名前 |
| `*.pdf`、`IMG_20??*` | ワイルドカードは名前全体に一致 |
| `=readme.md` | この名前と完全に一致するものだけ |

- 大文字と小文字、アクセント記号は区別しません（`cafe` で `Café`、`duong` で `Đường` が見つかります）。全角と半角も同じ文字として扱います。
- インデックスは使いません。毎回フォルダーを実際に読むので、結果は常に最新です。SSD では毎秒数千フォルダーを走査できます。HDD は初回が遅くなります。
- 結果の列は Name、Folder（検索したフォルダーからの相対パス。`.\` はその直下）、Date modified、Size、Type です。開く、名前の変更、コピー、切り取り、削除、ドラッグは通常どおり使えます。右クリック → **Open file location** で保存場所へ移動します。列見出しをクリックすると並べ替えます。
- 検索ボックスで Esc、Back、Backspace を押すとフォルダーに戻ります。隠しファイルは表示をオンにしているときだけ検索します。ジャンクションとシンボリックリンクはたどりません。
- プロファイルには検索タブのフォルダーが保存され、検索そのものは保存されません。

## ドラッグ＆ドロップ

- 別のペイン、一覧内のフォルダー、タブ（0.5 秒止めるとそのタブに切り替わる）、アドレスバーの区切り、サイドバーへドラッグできます。既定は**移動**で、**Ctrl** を押していると**コピー**になります。Esc でキャンセルします。
- エクスプローラーや他のアプリからドロップしたファイルはコピーされます（Shift を押すと移動）。

## クリップボード

Ctrl+C は複数の形式を同時にクリップボードに書き込むため、貼り付け先ごとに適した結果になります。

| 貼り付け先 | 結果 |
|---|---|
| エクスプローラー、このアプリ | 実際のファイル / フォルダー |
| Excel、Word、Outlook | **名前**を表示し、フルパスを指すハイパーリンク（Excel では 1 項目につき 1 行） |
| メモ帳、テキストボックス | フルパス |
| このアプリのアドレスバー | フルパス。Enter で移動 |

Office 2019（Excel、Word）で確認済みです。通常の Ctrl+C でハイパーリンクとして貼り付けられ、英語以外のファイル名も正しく扱えます。ファイル本体は不要でリンクだけが欲しいときは Ctrl+Shift+C を使います。

## 圧縮 / ドライブの取り出し

- **Compress to ZIP file**（右クリックメニュー）：アプリ自身で圧縮し、外部ソフトは不要です。バックグラウンドで動き、進捗表示とキャンセルができます。
  - 英語以外のファイル名もそのまま保持します（UTF-8）。4 GB を超えるファイルやアーカイブにも対応します（ZIP64）。
  - 動画・画像・圧縮済みのファイル（mp4、jpg、zip など）は、速度のため再圧縮せずにそのまま格納します。
  - アーカイブ名は、現在のフォルダー内の `<最初の項目>.zip` です（同名があれば "(2)" を付けます）。
- **Add to .7z archive (7-Zip)**：インストール済みの 7-Zip を使い、7-Zip 自身の進捗ウィンドウが表示されます。7-Zip がない場合はグレー表示になります。
- **Add to .7z with password…**：AES-256 で暗号化し、ファイル名も暗号化できます（パスワードがないとファイル一覧も見えません）。パスワードにアクセント付きなどの非 ASCII 文字が含まれると、アプリが確認します。ベトナム語入力ツール（Unikey、EVKey など）が "a1"/"as" のような入力を "á" に変えてしまうことがよくあるためです。
- **Extract here / Extract to "<名前>\"**（.zip、.7z、.rar、.tar、.gz、.tgz、.bz2、.xz を右クリック）：7-Zip を使います（パスワード付きのアーカイブは 7-Zip がパスワードを尋ねます）。7-Zip がない場合は Windows 標準の `tar.exe` を使います。"Extract to" は専用のフォルダーを作ります（同名があれば "(2)" を付けます）。
- **Eject**（This PC またはサイドバーで USB メモリ / 外付けドライブを右クリック）：そのドライブを表示中のペインを This PC に戻してから、Windows に「安全な取り外し」を要求します。他のプログラムがドライブを使用中の場合は、そのプログラム名を表示します。

## コピー / 移動 / 削除

- バックグラウンドで動作します。進捗ウィンドウは操作が 0.5 秒を超えたときだけ表示され、項目数・MB・速度と Cancel ボタンがあります。
- 同名のとき：Replace / Skip / Keep both（"a (2).txt"）から選べ、"Do this for all conflicts" オプションもあります。コピー元のフォルダー自身に貼り付けると "a - Copy.txt" を作ります。
- 同じドライブ内の移動は名前の変更なので一瞬です。別のドライブへはコピーしてから元を削除します。
- **Del（ごみ箱）**：内蔵の NTFS ドライブでは、項目をそのドライブの `$Recycle.Bin` に直接移すだけ（名前の変更のみ）なので、数十万ファイルのフォルダーでもほぼ一瞬です。ごみ箱からの復元も通常どおりできます。FAT/exFAT の USB ドライブ、ネットワークドライブ、使用中のファイルを含むフォルダーでは Windows の方法を使います。
- **Shift+Del（完全削除）**：`rm -rf` と同じ方式で、`rmdir /s /q` と同等の速さです。ロックされたファイルはスキップし、削除後に削除できなかったファイルを 1 回だけまとめて表示します。
- コピーを途中でキャンセルすると、コピー途中のファイルは削除されます。
